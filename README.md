# مكين 64 · مستكشف المجمع ثلاثي الأبعاد

موقع تفاعلي لاستكشاف مجمع مكين: اختيار المبنى ثم الدور ثم الشقة، مع تصاميم داخلية واقعية وجولة 360° كاملة داخل الشقة: 10 غرف، ونقدر نبص للسقف والأرض، وننتقل بين الغرف من الأبواب.

- `index.html` الموقع كاملًا (three.js من jsDelivr).
- `models/` مجسّمات Blender الأصلية (makeen-102 والشقة والمحيط) محفوظة كنص base64.
- `renders/` صور التصميم الداخلي.
- `pano360/` صور 360° لكل غرفة (equirectangular 2:1). أماكن الأبواب في كل صورة متسجلة في `TOUR` جوه `index.html`.
- `draco/` فك ضغط Draco للمجسّمات.

روابط مباشرة: `#tour` للجولة، أو `#tour=kitchen` لغرفة معيّنة، و`#unit=C-202` لشقة معيّنة.

للتشغيل محليًا: أي سيرفر ملفات ثابت، مثل `python3 -m http.server` داخل المجلد.
